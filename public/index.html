내 Zepp 계정으로 설치 QR 발급

워치메이커 접속 코드 없이 사용할 수 있습니다. 아래에서 프로젝트를 저장한 다음 Codespaces에서 Zeus를 실행하고, 워치와 연결된 Zepp 계정으로 로그인하세요.

  1. GitHub Codespaces를 브라우저에서 열고 Explorer의 Upload…로 watchface-preview.zip을 올립니다. 이름에 (1)이 붙었다면 파일 이름을 맞춰 주세요.
  2. ZIP을 올린 폴더의 터미널에서 최초 로그인 명령을 실행합니다. 터미널에 나온 링크에서 같은 Zepp 계정으로 로그인한 뒤 주소창의 최종 localhost 주소를 같은 터미널에 붙여넣습니다.
  3. QR 발급 명령을 실행하고 터미널에 나온 QR을 여백까지 캡처합니다. Zepp의 기기 → 일반 → 개발자 모드 → + → 스캔을 열고 앨범에서 캡처를 고릅니다.
GitHub Codespaces 열기 개발자 모드 켜기

Zepp 스캔 화면의 앨범 메뉴는 앱 버전에 따라 다를 수 있습니다. QR 발급에 실패하면 터미널 메시지에서 로그인 상태와 선택한 워치 모델을 확인하세요.
